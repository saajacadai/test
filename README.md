# لوحة متابعة الخطة التشغيلية

صفحة اللوحة منشورة عبر GitHub Pages. البيانات تُقرأ لحظيًا من Google Apps Script المرتبط بملف الخطة، ولا تُحفظ أي بيانات في هذا المستودع.

- العرض العام: نظرة عامة، والنقاط المركزية، والجدول الزمني.
- المبادرات التفصيلية والتعديل: بعد تسجيل الدخول بحساب Google شُورك معه ملف الخطة.
